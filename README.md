# Sulav Poudel Portfolio

A static, responsive portfolio site built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly in a browser, or use a local static server:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy

### GitHub Pages
1. Create a repository named `portfolio` in the `603codes` GitHub account.
2. Upload these files to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch** and select `main` / root.

### Vercel
Import the repository and deploy it as a static site. No build command is needed.

## Included active tool

The portfolio includes `cbt.html`, which routes visitors to the active CBT Exam Portal from the earlier website. This keeps the tool accessible from the new portfolio without overwriting or replacing its current version.
